# Особенности проекта
## 1. Эволюционный поиск нейронных архитектур (AutoML)
Данный модуль представляет собой реализацию стохастической оптимизации нейронных сетей посредством алгоритмов **нейроэволюции**. 

В отличие от классического градиентного спуска, данный подход позволяет проводить автоматизированный поиск оптимальной топологии графа вычислений и гиперпараметров в заданном многомерном пространстве поиска.

### Архитектура «Островной модели» (Island Model)
Движок базируется на концепции **параллельных изолированных популяций (островов)**. Данный подход минимизирует риск преждевременной сходимости в локальный минимум за счет реализации различных стратегий селективного давления:
*   **Sniper Objective:** ориентирован на максимизацию аппроксимирующей способности модели (точность).
*   **Efficiency Objective:** реализует поиск в рамках оптимальности между точностью и вычислительной сложностью (количество параметров).
*   **Speed Objective:** оптимизирует скорость работы и время обучения, минимизируя глубину графа.

### Генетические операторы и динамика популяции
Процесс эволюции управляется набором стохастических операторов, действующих на **генотип** (структурную конфигурацию):
*   **Кроссинговер (Crossover):** рекомбинация архитектурных блоков двух родительских особей для наследования наиболее эффективных паттернов связей.
*   **Мутация (Mutation):** случайное варьирование гиперпараметров (скорость обучения, тип оптимизатора) и структурные изменения (модификация размерности слоев, инъекция или элиминация слоев).
*   **Механизм катаклизмов (Cataclysm):** инструмент поддержания генетического разнообразия. При стагнации популяции инициируется массовая элиминация неэффективных особей и замещение их новыми случайными структурами.
*   **Миграция (Migration):** периодический обмен генотипами между островами для распространения наиболее адаптивных признаков.

### Функция приспособленности (Fitness Function)
Ключевой особенностью является **регуляризация на основе обобщающей способности**. Функция фитнеса включает штрафной коэффициент за разрыв  между метриками на обучающей и валидационной выборках, что подавляет развитие архитектур, склонных к переобучению.

## 2. Ядро автоматического дифференцирования (Autograd Engine)
Центральным компонентом системы является класс `Tensor`, реализующий динамический граф вычислений. 
*   **Механизм Backpropagation**: реализовано дифференцирование в обратном режиме (reverse-mode AD). Каждый тензор хранит ссылки на родительские узлы (`_prev`) и функцию градиента (`_backward`), что позволяет автоматически вычислять производные сложных композитных функций через топологическую сортировку графа.
*   **Поддержка широковещания (Broadcasting)**: система корректно обрабатывает операции над тензорами различных размерностей, автоматически агрегируя градиенты при выполнении арифметических операций (`_handle_broadcasting`).
*   **Операторный базис**: реализована поддержка основных математических операций: матричное умножение (`@`), возведение в степень, экспонента, логарифм и тригонометрические функции активации, что позволяет писать произвольные функции потерь без жёсткого задавания производной для каждой.

## 3. Модульная объектно-ориентированная архитектура
Фреймворк придерживается принципа абстракции слоев, реализованного через базовый класс `Module`.
*   **Композиция слоев**: класс `Sequential` позволяет формировать конвейерную архитектуру нейронной сети, где выход одного слоя транслируется на вход следующего.
*   **Инкапсуляция параметров**: каждый слой (например, `Linear`) самостоятельно управляет своими обучаемыми параметрами (веса $W$, смещения $b$), обеспечивая удобный интерфейс для оптимизаторов через метод `parameters()`.


## 4. Библиотека алгоритмов оптимизации
В проекте реализованы современные методы стохастической оптимизации первого порядка:
*   **SGD**: реализация классического стохастического градиентного спуска, обеспечивающего итеративное обновление параметров вдоль вектора антиградиента.
*   **Momentum**: интеграция инерционного фактора, который аккумулирует «скорость» обновления (velocity), позволяя стабилизировать траекторию оптимизации и ускорить сходимость за счет учета накопленного импульса предыдущих шагов.
*   **Adam**: адаптивный алгоритм. Реализована коррекция смещения (bias correction) для моментов первого и второго порядков.
*   **Gradient Clipping**: механизм ограничения нормы градиента для предотвращения проблемы «взрывающихся градиентов» в глубоких или рекуррентных структурах. Является обёрткой для других оптимизаторов.

## 5. Функционал потерь и метрик
Система предоставляет инструментарий для оценки качества моделей в задачах регрессии и классификации:
*   **Функции потерь**: включают среднеквадратичную ошибку (`MSE`), бинарную кросс-энтропию (`BCE`) и многоклассовую кросс-энтропию (`CrossEntropy`), математически интегрированные с графом вычислений.
*   **Аналитические метрики**: реализованы стандартные статистические показатели качества: `Accuracy`, `Precision`, `Recall`, `F1-Score`, а также коэффициенты детерминации (`R2Score`) и средняя абсолютная ошибка (`MAE`).

## 6. Конвейер обработки данных (Data Pipeline)
Реализована абстракция для работы с данными, минимизирующая накладные расходы на память:
*   **Dataset**: интерфейс для индексации и хранения выборок, включая метод загрузки напрямую из CSV-файлов.
*   **DataLoader**: итерируемый объект, обеспечивающий перемешивание (shuffling) и формирование батчей (mini-batching), что является необходимым условием для эффективного обучения нейронных сетей.
